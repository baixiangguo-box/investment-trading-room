# 投资交易室 1.3.0：安装与使用

## 安装前只需确认系统

- Windows 11，64 位 x64 电脑：使用 Windows 文件夹中的 OneClick EXE。
- macOS 13 或更新版本：打开苹果菜单 → 关于本机；显示 Apple 芯片的使用 arm64，显示 Intel 处理器的使用 x64。
- 安装包包含 Electron、Chromium、Node 和 SQLite 运行环境，无需预装 Node.js、npm、Python、Homebrew、浏览器插件或数据库。Apple Silicon 使用 arm64，不需要 Rosetta。
- 安装可以离线进行；正常获取行情需要联网。电脑需有足够存储空间，并允许安装自己的应用。

## Windows 一键安装

1. 双击 `InvestmentTradingRoom-OneClick-Setup-1.3.0-x64.exe`。
2. 如果系统显示安全确认，先核对下载来源和校验值，再按系统提供的允许流程操作。此包未数字签名，不能保证完全无系统确认。
3. 安装完成后，打开桌面或开始菜单中的“投资交易室”。无需再运行源码或任何命令。

另有 `InvestmentTradingRoom-Setup-1.3.0-x64.exe` 原向导版，供需要选择安装目录的用户使用；桌面交付默认提供一键版。

## Mac 安装

1. 选择自己芯片对应的 `InvestmentTradingRoom-Mac-1.3.0-arm64.pkg` 或 `InvestmentTradingRoom-Mac-1.3.0-x64.pkg`，双击。
2. 按系统 Installer 的继续、安装提示操作；可以选择仅当前用户或本机所有用户。系统要求授权时由本人完成。
3. 从 Applications（应用程序），或仅当前用户安装时的个人 Applications 文件夹，打开“投资交易室”。

DMG 是替代方案：打开同架构 `.dmg`，将“投资交易室”拖到 Applications，再从 Applications 打开。ZIP 为解压后复制 `.app` 的分发方案；不要把 Windows EXE 用在 Mac 上。

**Mac 版本为预览，应用仅 ad-hoc 开发签名，PKG 未签名，未完成 Developer ID/公证或真实 Mac GUI 验收。** 下载后的系统安全确认可能需要手动处理；不承诺所有 Mac 完全免确认。核对来源、文件校验值后使用 macOS 自身提供的允许流程，不关闭 Gatekeeper/SIP，不删除下载隔离属性。提示文件损坏时先重新下载并核对校验值，不强行绕过。

## 首次使用

1. 首次打开创建模拟账户，填写昵称和虚拟初始资产。
2. “行情”查看指数、板块、热门股票及沪深京列表；名称或代码搜索，点“更多”进入完整列表。
3. 点击股票进入详情，切换分时、日 K、周 K、月 K；图表下方查看成交量，鼠标或键盘定位价格和成交量。
4. 股票右侧 `+` 加入自选，`−` 移除；在“自选”查看或进入股票详情。
5. “交易”选择证券、买卖方向、限价和数量，检查后提交模拟委托。委托页查看或撤销，持仓页查看持仓，成交页查看记录。
6. “账户”查看资产、盈亏和资金流水；“充值账户资产”只增加虚拟现金。重置清空持仓与记录，弹窗可选择是否清空自选，重置前自动备份。
7. 账户页可导出 JSON 备份、预览并恢复。更换电脑、跨 Windows/Mac 或升级前，先保存外部备份；恢复前核对昵称、资产和记录。

所有交易都是本地模拟，没有真实资金或券商账户。成交取决于有效行情、可用盘口和本软件支持的连续竞价规则；并非提交就一定立即成交。行情失败时保留缓存，过期报价不会成交。交易日历当前覆盖 2026 年，未知年份会暂停成交，需更新软件。

## 数据、退出与故障处理

- Windows 数据：系统“文档”目录下的 `投资交易室数据`。卸载默认保留账户，但重装或换电脑前仍应导出备份。
- Mac 数据：`~/Library/Application Support/org.investment.tradingroom`。程序放置位置与账户目录分开。
- Windows 关窗退出；Mac 关窗继续驻留，点击 Dock 重开，Command+Q 完全退出。Mac 编辑快捷键使用 Command 系列。
- 没有行情：确认联网、等待公开接口恢复；账户和缓存仍可访问。不要凭缓存报价判断成交。
- 安装器被拦截：核对 GitHub 来源和 SHA-256，再遵循系统安全界面。未签名限制不等于需要另外安装运行环境。
- 升级：导出备份 → 退出程序 → 安装新版。不要主动删除账户目录，也不要把别人提供的账户数据库直接覆盖到本机。
